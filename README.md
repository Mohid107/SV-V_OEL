# Smart Autonomous Cold-Chain Delivery & Control System (SACDCS)

Welcome to the **SACDCS Quality Engineering Repository**. This repository contains the complete software quality engineering documentation, requirements analysis, state models, operation schemas, and formal constraints for a national health authority's autonomous vaccine and medicine delivery fleet.

## Repository Structure

*   `docs/` - Static web portal documentation (Robots, Operators, Project Artefacts)
*   `requirements/` - Task 1: Master Requirements Baseline
*   `change-management/` - Task 2: Version-Controlled Change Log & RTM
*   `models/` - Task 3: State Modelling, Transition Tables & Mermaid Diagrams
*   `operations/` - Task 4: Conservation Chamber Operation Identification & Schemas
*   `constraints/` - Task 5: Formalised System Constraints & Violation Scenarios

## Project Overview
The SACDCS integrates autonomous delivery robots equipped with sealed conservation chambers, supervised remotely from a Mission Control Centre over a low-bandwidth, delayed link. It features role-based access control, Safe Mode fallback, and automated railway level-crossing integration (ARLCCS).
